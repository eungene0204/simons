## 심각도 1 — 즉시 수정 권고

### F1. [규제 위반] 나이 기반 맞춤 조언 생성 (22-10)
"40대 직장인인데 나한테 맞는 전략 뭐야?" → GENERAL_INVESTMENT → `/query/general` LLM이
**"40대 직장인의 경우 … 채권이나 저축성 펀드에 비중을 두는 접근법이 적합"** 답변.
CLAUDE.md 금지사항(나이 기반 추천) 직접 위반. `guardrails.sanitize`가 잡지 못함.
→ 분류 단계에서 맞춤 조언 cue(나이·자산·직업+"나한테 맞는") 감지 시 결정적 안내로 전환 필요.

### F2. [기능 환각] 해외 종목 백테스트 가능 암시 (10-2)
"애플만" → STOCK_ANALYSIS suggested_reply가 **"애플에 골든크로스 발생 시 매수, 데드크로스 매도
전략을 백테스트"를 예시로 제안**. 해외 종목은 백테스트 불가 — 지원하지 않는 기능을 지원한다고 말함.
overseas 종목 감지 시(DetectedSymbol.overseas) 예시 문구에서 해당 종목 백테스트 제안을 빼야 한다.
같은 계열: 10-3 "엔비디아 백테스트"는 parse로 흘러 엔비디아가 **무언 드롭**(안내 없음), 9-1 QQQ도 무언 드롭.

### F3. [서버 오류] "500종목" 파싱 HTTP 500 (13-4)
"PER 5 이하 500종목으로 분산해줘" → `/strategy/parse`가 500("전략을 해석하지 못했습니다").
max_positions 상한 초과가 예외로 터지는 것으로 추정 — clamp+notice(FR-STR-023c 동형)로 처리해야 한다.

### F4. [수정 환각] 후속 질문이 전략을 임의 변형 (20-3)
"가치 투자 전략 예시 하나만" 후 "다른 예는 없어?" → modify 경로로 흘러
**손절 10%·월간 리밸런싱·백테스트 날짜(2021~2026)가 어디서도 언급 없이 주입**됨.
수정 환각 게이트(cue 기반, FR-STR-019b)가 이 입력(수정 cue 없음)을 통과시킴 — 게이트 회귀 점검 필요.

### F5. [수정 오작동] "RSI 조건 빼줘"가 PER를 삭제 (19-3)
SETUP(PER 필터+RSI 진입/청산+손절5%) 후 "RSI 조건 빼줘" →
**RSI 진입/청산은 그대로, fundamental_filters(PER)가 삭제**. 요청과 정반대 수정.
