## 1. 포지셔닝

### 1.1 한 문장 포지셔닝

> **"아무도 당신에게 종목을 찍어주지 않습니다. 당신의 가설을 검증해 드립니다."**

### 1.2 왜 이 포지셔닝인가

| 근거 | 설명 |
|---|---|
| 규제상 유일하게 안전한 자리 | 추천·전망·맞춤 조언은 전부 금지. "검증 도구"는 금지 목록과 충돌하지 않는 유일한 정체성 |
| 시장의 반대편이 비어 있다 | 국내 주식 서비스 마케팅의 대부분이 "종목 추천·리딩·수익 인증". 리딩방 사기 뉴스가 반복될수록 반대 포지션의 신뢰 가치가 올라간다 |
| 경쟁사가 따라 하기 어렵다 | 추천이 수익 모델인 서비스는 "추천하지 않습니다"를 말할 수 없다 |
| 제품 실체와 일치 | 자연어 전략 빌더 → 백테스트 → 검증(워크포워드/몬테카를로) → 가상계좌 시뮬레이션. 제품이 실제로 하는 일이 곧 메시지 |

### 1.3 메시지 위계 (모든 채널 공통)

1. **1차 (후킹):** "그 전략, 진짜 통했는지 직접 확인해 보세요"
2. **2차 (차별점):** "코딩 없이, 말로 하면 백테스트가 됩니다"
3. **3차 (신뢰):** "상장폐지 종목까지 포함한 생존편향 없는 데이터" / "과거 데이터 기반 시뮬레이션이며 미래 수익을 보장하지 않습니다"

디스클레이머(3차의 후단)는 신뢰 요소로 **적극적으로 노출**한다. 숨기는 문구가 아니라 차별화 문구다.

### 1.4 안티 포지셔닝 (하지 않는 것을 명시)

랜딩·소개 문구에 "우리가 하지 않는 것" 섹션을 넣는다:

- 종목을 추천하지 않습니다
- 시장을 전망하지 않습니다
- 수익을 보장하지 않습니다
- 리딩방을 운영하지 않습니다

## 2. 타깃 세그먼트

### 세그먼트 A — 퀀트 입문 희망자 (최우선, 가장 큼)

- **누구:** "퀀트 투자 해보고 싶은데 코딩을 못 한다 / 엑셀도 버겁다"는 20~40대 직장인 투자자. 강환국류 퀀트 서적·유튜브를 봤지만 실행을 못 한 층.
- **페인:** 퀀트 책 → "이제 백테스트 하세요" → 파이썬 벽에서 이탈. 기존 퀀트 툴은 조건식 문법 학습이 필요.
- **우리의 답:** 자연어 전략 빌더. "PER 10 이하, 시총 상위 200개 중에서 RSI 30 밑이면 사줘"가 그대로 전략이 됨.
- **핵심 메시지:** "말로 하면 백테스트가 됩니다"
- **채널:** SEO(입문 키워드), 유튜브 퀀트 콘텐츠 시청자, 재테크 카페

### 세그먼트 B — 검증 욕구가 있는 일반 투자자

- **누구:** 유튜브·책·커뮤니티에서 주워들은 전략("골든크로스 사면 오른다더라", "저PER이 답이다")의 진위가 궁금한 능동적 개미.
- **페인:** 검증할 방법이 없어서 믿거나 말거나로 매매. 리딩방·유료 카톡방에 데인 경험.
- **우리의 답:** 30초 만에 그 통념을 10년치 데이터로 돌려볼 수 있음.
- **핵심 메시지:** "그 말, 지난 10년 데이터로 확인해 보세요"
- **채널:** 커뮤니티 시딩(통념 검증 콘텐츠), 검색(전략명+수익률 키워드)

### 세그먼트 C — 기존 퀀트 툴 사용자 (전환)

- **누구:** 젠포트·퀀터스·퀀트킹 등 기존 툴 사용자/이탈자. (경쟁사 현황은 분기 1회 재확인 — 요금·기능 변동 잦음)
- **페인:** 조건식 문법 학습 비용, 생존편향 의심, 검증 기능 부재, 요금.
- **우리의 답:** PIT 생존편향 제거 유니버스, 워크포워드/몬테카를로 검증, 자연어 입력, 테마·업종 유니버스.
- **핵심 메시지:** "생존편향 없는 데이터로, 과최적화까지 검증"
- **채널:** 비교 키워드 SEO("젠포트 대안" 등), 퀀트 오픈카톡·커뮤니티

**우선순위: A > B > C.** A가 시장이 가장 크고 우리 차별점(자연어)이 가장 강하게 작동한다. C는 볼륨은 작지만 전환 시 유료화 확률이 가장 높다.

## 3. 코어 키워드 전략 (SEO)

### 3.1 키워드 클러스터 맵

검색량·난이도는 네이버 검색광고 키워드도구 + Google Keyword Planner로 실측 후 이 표를 갱신한다(분기 1회). 아래는 우선순위 가설.

#### 클러스터 1 — 카테고리 키워드 (전환 의도 높음, 최우선)

| 키워드 | 의도 | 대응 페이지 |
|---|---|---|
| 주식 백테스트 | 도구 탐색 | 랜딩 (메인 타깃 키워드) |
| 백테스트 사이트 / 백테스트 무료 | 도구 탐색 | 랜딩 + 요금 페이지 |
| 백테스팅 프로그램 | 도구 탐색 | 랜딩 |
| 퀀트 투자 프로그램 / 퀀트 사이트 | 도구 탐색 | 랜딩 |
| 코딩 없이 퀀트 / 노코드 퀀트 | 도구 탐색 | 자연어 빌더 소개 페이지 |
| 주식 시뮬레이션 / 모의투자 사이트 | 도구 탐색 | 가상계좌 소개 페이지 |

#### 클러스터 2 — 전략 검증 키워드 (콘텐츠 유입, 볼륨 큼)

"전략명 + 수익률/백테스트/후기" 조합. 각 키워드가 블로그 글 1편에 대응.

| 키워드 예시 | 콘텐츠 |
|---|---|
| 마법공식 한국 수익률 / 마법공식 백테스트 | 통념 검증 #: 마법공식 |
| 골든크로스 수익률 / 골든크로스 매매법 | 통념 검증 #: 골든크로스 |
| 저PER 주식 수익률 | 통념 검증 #: 저PER |
| RSI 30 매수 / RSI 과매도 매매 | 통념 검증 #: RSI 역추세 |
| 듀얼모멘텀 한국 / 모멘텀 전략 백테스트 | 통념 검증 #: 모멘텀 |
| 볼린저밴드 매매법 수익률 | 통념 검증 #: 볼린저밴드 |
| 배당주 투자 수익률 | 통념 검증 #: 고배당 |
| 시가총액 하위 소형주 전략 | 통념 검증 #: 소형주 효과 |
| 1월 효과 / 계절성 매매 | 통념 검증 #: 캘린더 효과 |
| 이동평균선 매매법 | 통념 검증 #: MA 크로스 |

#### 클러스터 3 — 지표·용어 사전 (프로그래매틱 SEO, 롱테일 다량)

| 키워드 패턴 | 대응 |
|---|---|
| RSI란 / PER PBR 차이 / MDD란 / 샤프지수 계산 / CAGR 뜻 / ROE ROA 차이 / 스토캐스틱 보는법 / MACD 신호 | 지표 사전 페이지 (지표당 1페이지, 엔진이 지원하는 지표 전체) |

- 이미 엔진에 지표 20여 종 + 재무 지표 10종이 있으므로 **페이지 30~40개를 반자동 생산 가능**.
- 각 사전 페이지 하단에 "이 지표로 전략을 만들어 직접 백테스트해 보세요" CTA → 해당 지표가 프리필된 빌더로 딥링크.
- 설명은 "무엇인가 + 계산식 + 과거 데이터에서의 통계적 사실"까지만. "이 지표가 좋다/유리하다"는 금지.

#### 클러스터 4 — 경쟁·비교 키워드 (볼륨 작지만 전환율 최고)

| 키워드 | 주의 |
|---|---|
| 젠포트 대안 / 젠포트 무료 / 젠포트 후기 | 비교 페이지. **타사 비방 금지, 기능 사실 비교만.** 타사 요금·기능은 캡처 날짜 명기 |
| 퀀터스 무료 / 퀀터스 후기 | 〃 |
| 퀀트킹 사용법 | 〃 |
| 인텔리퀀트 (서비스 종료 여부 확인) | 종료가 사실이면 "인텔리퀀트 대안" 페이지는 이주 수요를 그대로 받는 페이지가 됨 — 우선 확인 |

#### 클러스터 5 — 문제 인식 키워드 (상단 퍼널, 신뢰 구축)

| 키워드 | 콘텐츠 |
|---|---|
| 리딩방 사기 / 주식 리딩방 후기 | "리딩방 없이 스스로 검증하는 법" — 안티 포지셔닝 콘텐츠 |
| 백테스트 함정 / 과최적화 | "백테스트가 거짓말하는 5가지 방식(생존편향·과최적화·미래참조 등)" — 기술 신뢰 콘텐츠. 우리 제품의 PIT·워크포워드가 자연스럽게 등장 |
| 생존편향 | 〃 |

### 3.2 기술 SEO 체크리스트 (Next.js)

- [ ] 모든 공개 페이지에 고유 `<title>` + `meta description` (금지 표현 검수 통과본)
- [ ] `sitemap.xml` 자동 생성 (블로그·사전 페이지 포함) + Search Console / 네이버 서치어드바이저 등록
- [ ] 블로그·사전 페이지는 SSG/ISR로 — 로그인 없이 크롤 가능해야 함
- [ ] 구조화 데이터: 사전 페이지 `Article`, 요금 `Product`, FAQ 페이지 `FAQPage`
- [ ] Open Graph 이미지: 페이지별 자동 생성 (백테스트 공유 카드와 동일 파이프라인 재사용)
- [ ] 핵심 랜딩 LCP < 2.5s (모바일 성능 패스 기준 유지)
- [ ] 내부 링크: 사전 ↔ 통념 검증 글 ↔ 빌더 딥링크 삼각 연결

### 3.3 네이버 대응 (한국 시장 필수)

한국 검색의 절반 이상이 네이버다. 구글 SEO만으로는 부족하다.

- **네이버 블로그를 별도 운영** (자사 도메인 블로그와 이원화). 통념 검증 글의 요약본 + 원문 링크. 네이버는 자사 블로그를 우대하므로 중복 콘텐츠 걱정보다 배포 우선.
- **네이버 서치어드바이저** 등록 + 웹마스터도구 수집 요청.
- 지식iN: "백테스트 어떻게 하나요" 류 질문에 성실 답변 + 링크 (월 2~4건, 과하면 스팸 처리됨).
- 네이버 카페 활동은 [§4 커뮤니티](#4-커뮤니티-공략)에서 다룸.

## 4. 커뮤니티 공략

### 4.0 대원칙 — 시딩의 철칙

1. **광고 티가 나는 순간 끝.** 커뮤니티별로 계정을 키우고(활동 이력 2~4주), 제품 언급 없는 순수 기여 글이 제품 언급 글보다 3배 이상 많아야 한다.
2. **글의 주인공은 제품이 아니라 결과 데이터다.** "이 서비스 좋아요"(즉시 삭제·비난)가 아니라 "골든크로스 10년 돌려봤는데 결과가 의외네요"(토론 유발) 형식.
3. **제품명은 본문이 아니라 댓글에서.** "어디서 돌리셨어요?" 질문이 나오면 그때 답한다. 안 나오면 본문 말미에 "돌려본 도구는 프로필에" 수준까지만.
4. **규제 문구는 커뮤니티에서도 동일 적용.** "이 전략 좋다/하세요"는 커뮤니티 글에서도 금지. "과거 구간에서 CAGR X%, MDD Y%였다. 미래는 모른다"로 끝맺는다.
5. **운영자 신분 투명성:** 직접적으로 물으면 만든 사람이라고 밝힌다. 잠입 마케팅 들통은 커뮤니티에서 영구 낙인이다.

### 4.1 채널별 공략표

| 채널 | 성격 | 공략법 | 빈도 | 리스크 |
|---|---|---|---|---|
| **디시 주식갤러리** | 트래픽 최대, 어그로 문화, 링크 스팸에 민감 | 자극적 제목의 검증 글("골든크로스 믿는 사람 아직 있냐? 10년 돌려봄")+결과 스샷. 링크는 댓글 요청 시만 | 주 1 | 조리돌림 리스크 — 데이터 틀리면 역효과. 결과 검증 2회 후 게시 |
| **디시 시스템트레이딩/알고리즘 마이너갤** | 소수 정예, 기술적 대화 가능 | 방법론 글(PIT 유니버스 구축기, 체결 모델링 이야기). 만든 사람임을 밝히고 피드백 요청 | 격주 | 낮음. 오히려 초기 헤비유저 발굴처 |
| **에펨코리아 금융/주식** | 유머+정보 혼합, 스압 짤글 선호 | 결과를 짤 중심으로 재구성한 통념 검증 글 | 주 1 | 중간 |
| **뽐뿌 재테크포럼** | 실속·가성비 문화 | "무료로 백테스트 해본 후기" 형식(체험 후기 톤) | 격주 | 중간 |
| **클리앙 재테크 소모임** | 점잖은 톤, 광고 초강경 | 순수 정보글만. 제품 언급은 질문 받을 때만 | 월 1~2 | 높음(강퇴) — 보수적으로 |

| **X(트위터) 주식 계정** | 핀플루언서 리트윗 구조 | 검증 결과를 이미지 1장+요약 3줄 포맷으로 정기 발행. 팔로워보다 리트윗 최적화 | 주 2~3 | 낮음. 공유 카드 기능과 시너지 최대 |

### 4.2 유튜브 — 직접 운영 대신 협업 우선

- 직접 채널 운영은 비용 대비 느리다. **초기에는 기존 퀀트·재테크 유튜버 협업**이 효율적.
- 협업 형식: "구독자가 궁금해하는 전략을 대신 검증해 드립니다" — 유튜버가 소재를 얻고, 우리는 노출을 얻는 구조. 금전 협찬 전에 이 형식부터 제안.
- **주의:** 유튜버가 결과를 "이 전략 좋네요, 하세요"로 해석해 말하면 우리 브랜드가 같이 엮인다. 협업 시 **표현 가이드라인(§8) 전달을 계약 조건**으로.
- 타깃 채널 리스트업 기준: 구독자 1만~20만의 퀀트/데이터 기반 채널 (대형보다 중형이 응답률·단가·타깃 순도 모두 유리).

### 4.3 자체 커뮤니티 (장기)

- 제품 내 "공개 전략" 갤러리가 곧 커뮤니티 자산. 사용자 생성 전략 + 백테스트 결과가 쌓이면 그 페이지 자체가 SEO 자산이자 재방문 이유가 된다.
- 단, 공개 전략 정렬 기준에 주의: "수익률 순 TOP 10" 노출은 사실상 전략 추천으로 읽힐 수 있음 → **"최신순/조회순" 기본**, 수익률 정렬은 사용자가 직접 선택했을 때만.

## 5. 콘텐츠 엔진 — "통념 검증" 시리즈

### 5.1 왜 이것이 코어인가

- 제품이 곧 콘텐츠 생산 도구다: 글 1편 = 백테스트 1회 + 해설. 한계 생산 비용이 극히 낮다.
- 하나의 검증 결과가 **블로그(SEO) → 네이버 블로그(네이버 검색) → 커뮤니티 글(시딩) → X 이미지(바이럴) → 유튜버 소재 제공(협업)** 5개 채널에 재활용된다. **1소스 5배포**가 기본 공정.
- 클러스터 2 키워드와 1:1 대응 → 콘텐츠가 곧 SEO.

### 5.2 표준 포맷 (규제 안전 내장)

```
1. 통념 소개 — "○○하면 오른다는 말, 많이 들어보셨을 겁니다"
2. 검증 설계 — 유니버스·기간·매수/매도 규칙·비용 가정 명시 (재현 가능하게)
3. 결과 — CAGR, MDD, 샤프, 거래 횟수, 수익곡선. 과거형 서술만
4. 구간 분해 — 연도별/장세별로 갈리는 지점 (스토리의 재미 담당)
5. 한계 고지 — "과거 데이터 기반 시뮬레이션이며 미래 수익을 보장하지 않습니다.
   특정 전략의 사용을 권하지 않습니다"
6. CTA — "다른 조건으로 직접 바꿔서 돌려보세요" + 해당 전략 프리필 딥링크
```

- 결론을 "그러니 하세요/하지 마세요"로 내리지 않는다. **"결과는 이랬다, 판단은 당신이"**가 시리즈의 시그니처이자 규제 방어선.
- CTA의 프리필 딥링크가 핵심 전환 장치: 글에서 본 전략을 클릭 한 번에 이어서 실험 → aha moment 직행.

### 5.3 초기 12편 라인업 (커뮤니티 반응 예상 순)

1. 골든크로스 — 가장 유명한 통념, 어그로 최상
2. 마법공식 한국 — 책 판매량만큼 검색량 존재
3. 저PER — 가치투자 논쟁 유발
4. RSI 30 매수 — 단타족 유입
5. "떨어지는 칼날" 물타기 vs 손절 — 논쟁 최대
6. 배당주는 안전한가 (MDD 관점)
7. 소형주 효과 — 퀀트 고전
8. 1월 효과/계절성
9. 거래량 급증 따라잡기
10. 볼린저밴드 하단 매수
11. 듀얼모멘텀 한국 적용
12. "백테스트가 거짓말하는 5가지" (기술 신뢰 콘텐츠, 클러스터 5)

### 5.4 생산 공정

- 주 1편. 백테스트 실행 → 결과 2회 재검증(수치 오류=커뮤니티 조리돌림) → 초안 → **금지 표현 체크리스트(§8) 검수** → 5채널 배포.
- 모든 수치에 실행 조건(기간·유니버스·비용 가정·엔진 버전)을 각주로. 재현 가능성이 신뢰 = 브랜드.

## 6. 바이럴 루프 — 결과 공유 카드

- **기능 요구:** 백테스트 결과를 이미지 카드(수익곡선 + CAGR/MDD/샤프 + 전략 요약 + 널스탁 로고 + "과거 데이터 기반 시뮬레이션" 문구 고정 삽입)로 내보내기. 링크 공유 시 OG 이미지로 동일 카드.
- 공유 링크는 **해당 전략을 열람+복제해 볼 수 있는 페이지**로 연결 → "남의 결과 구경 → 내가 조건 바꿔 실험"이 가입 동선.
- 디스클레이머가 카드에 박제되므로 사용자가 어디에 공유하든 규제 문구가 따라다닌다 — 바이럴과 규제 방어를 동시에 해결.
- X·커뮤니티 시딩 글도 전부 이 카드를 쓰므로 **마케팅 전 채널의 시각 통일성**이 생긴다.
- 우선순위: 90일 로드맵 내 상위 (제품 기능이지만 마케팅 ROI 최상).

## 7. 퍼널·지표

### 7.1 퍼널 정의

```
방문 → 첫 전략 입력 → 첫 백테스트 완주(aha) → 재방문(7일) → 쿼터 소진 → 유료 전환
```

**북극성 지표: 주간 "첫 백테스트 완주" 수.** (가입 수 아님 — 완주해야 제품 가치를 경험한 것)

### 7.2 채널별 측정

- UTM 규율: `utm_source`(dcinside/fmkorea/naver_blog/x/...) × `utm_content`(콘텐츠 슬러그). 커뮤니티는 링크 직접 투척이 적으므로 **"어떻게 알게 되셨나요?" 가입 설문 1문항** 병행.
- 콘텐츠별: 검색 유입(Search Console) → 딥링크 클릭률 → 완주율. 완주율 높은 소재를 차기 콘텐츠·광고 소재로 증폭.
- 주간 리뷰 1회: 소재별 완주 기여 순위만 본다 (지표 대시보드에 시간 쓰지 말 것).

### 7.3 초기 현실적 목표 (첫 90일)

| 지표 | 30일 | 60일 | 90일 |
|---|---|---|---|
| 발행 콘텐츠 누적 | 4편 | 9편 | 13편 + 사전 20페이지 |
| 주간 방문 | 300 | 1,000 | 3,000 |
| 주간 첫 백테스트 완주 | 30 | 120 | 400 |
| 유료 전환 | 측정만 | 측정만 | 전환율 베이스라인 확정 |

숫자는 목표라기보다 **중단/증폭 판단 기준선**. 90일에 완주 400 미달이어도 특정 채널 완주 전환율이 좋으면 그 채널에 집중.

### 8.2 자주 쓰는 안전 치환

| 쓰고 싶은 말 | 안전한 표현 |
|---|---|
| "수익률 좋은 전략" | "해당 구간 CAGR이 X%였던 전략" |
| "이 전략을 추천합니다" | "이 전략의 과거 결과를 직접 확인해 보세요" |
| "초보자에게 적합" | "조건식 없이 문장으로 입력할 수 있습니다" |

- 디스클레이머 자막 1회 필수

## 9. 유료 광고 (후순위 — 오가닉 검증 후)

- **원칙:** 오가닉으로 완주 전환율이 검증된 소재만 광고로 증폭한다. 검증 전 광고비 지출 금지.
- 시작 채널: ① 네이버 검색광고 — 클러스터 1·4 키워드만 (전환 의도 최상, CPC 감당 가능 범위 실측 후) ② 구글 검색광고 동일 키워드. 디스플레이·메타 광고는 보류.
- 금융 카테고리는 매체 심사가 까다로움 — §8 통과 소재는 심사에도 유리하다. "수익" 단어 자체를 광고 소재에서 배제하는 편이 심사·규제 양쪽에 안전.
- 예산 상한: 월 50만 원에서 시작, ROAS가 아니라 **완주당 비용(CPA)** 으로 판단.

## 12. 이 문서의 유지

- 키워드 표(§3.1)는 검색량 실측 후 갱신 — 실측 전까지 "가설" 상태.
- 커뮤니티 공략표(§4.1)는 시딩 2주 후 실반응으로 리스크·빈도 조정.
- 90일 회고 시점에 본 문서 전체 개정.
