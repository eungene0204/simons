# Overview
**Simons Project**는 개인 투자자가 코딩 지식 없이도 자신만의 퀀트 전략을 수립하고, 과거(Backtest)와 현재(Paper Trading) 시장 모두에서 검증할 수 있는 **AI 네이티브 퀀트 플랫폼**입니다.

사용자는 직관적인 GUI 폼을 통해 자동 매매 전략을 만들거나, **가상 화폐 'Null'을 이용해 직접 수동으로 투자를 연습**할 수 있습니다. 회사 고유의 AI 상승 확률 예측 모델을 전략 조건이나 수동 매매 판단의 보조 지표로 활용하여, 실제 자금을 투입하기 전 리스크 없이 실전 감각을 익히고 전략을 검증할 수 있습니다.

# Core Features
### 1. Strategy Builder (GUI Form)
* **What it does:** 사용자가 드롭다운과 입력 필드를 통해 매수/매도 조건을 설정합니다. (Phase 1 MVP 기준: Option A)
* **Why it's important:** 코딩을 못하는 일반 투자자도 논리적인 알고리즘 투자를 가능하게 합니다.
* **How it works:** 사용자가 선택한 지표(RSI, MA 등)와 AI 확률 조건이 JSON 형태로 변환되어 서버에 저장됩니다.

### 2. Backtesting Engine
* **What it does:** 과거 데이터를 기반으로 전략의 수익률, MDD, 승률을 시뮬레이션합니다.
* **Why it's important:** 전략의 역사적 성과를 확인하여 로직의 결함을 사전에 파악합니다.
* **How it works:** 과거 시점의 가격 데이터를 순차적으로 로드하여 가상의 매매를 체결하고 통계를 산출합니다.

### 3. AI Model Integration
* **What it does:** 종목별 상승 예측 확률(0~100%)을 제공하고, 이를 전략의 필터 조건으로 사용할 수 있게 합니다.
* **Why it's important:** 단순 기술적 분석의 한계를 넘어, 딥러닝 모델의 통찰력을 개인 전략에 결합하여 승률을 높입니다.
* **How it works:** `AI_Probability > 80%`와 같은 조건이 활성화되면, 백엔드는 모델 API를 호출하여 해당 조건을 검증합니다.

### 4. Forward Testing (Automated)
* **What it does:** 실시간 시장 데이터를 이용하여 현재 시점에서 가상 화폐 'Null'로 **자동 매매**를 수행합니다.
* **Why it's important:** '과거 편향(Look-ahead Bias)' 없이 현재 시장에서의 실제 통용 가능성을 검증합니다.
* **How it works:** 장 중 실시간 스케줄러가 전략 조건을 주기적으로 체크하고, 조건 만족 시 'Null' 원장을 업데이트합니다.

### 5. Manual Trading Interface
* **What it does:** 사용자가 직접 차트를 보고 '매수/매도' 버튼을 눌러 가상 화폐 'Null'로 거래를 실행합니다.
* **Why it's important:** 자동화된 로직 외에, 사용자의 직관이나 재량에 따른 투자를 연습하고 검증할 수 있습니다.
* **How it works:** 종목 상세 페이지에서 수량과 가격을 입력하여 주문을 전송하면, 실시간 호가와 매칭하여 즉시 체결 및 잔고 차감이 이루어집니다.

# User Experience
### User Personas
* **The Hybrid Trader:** 평소엔 자동 매매를 돌려놓지만, AI 추천 종목이 뜨면 직접 차트를 보고 수동으로 추가 매수하고 싶은 투자자.
* **The Aspiring Quant:** 코딩은 어렵고 엑셀 백테스트는 번거로운 30대 직장인.

### Key User Flows
1.  **Onboarding:** 회원가입 후 기본 자산(1,000,000 Null) 부여.
2.  **Auto Strategy:** '전략 만들기' -> GUI 폼 조건 입력 -> **'백테스트 실행' (과거 검증)** -> 결과 만족 시 '모의 투자 시작' (자동 실행).
3.  **Manual Trade:** '시장(Market)' 탭 이동 -> 관심 종목 클릭 -> 'AI 확률' 확인 후 '매수' 버튼 클릭 -> 포트폴리오 반영.
4.  **Review:** 대시보드에서 '자동 매매 성과'와 '수동 매매 성과'를 분리하여 확인.

# Technical Architecture
### System Components
* **Frontend:** React/Next.js (Interactive Form UI, Order Entry UI).
* **Backend API:** Python FastAPI (Handling both Scheduler-triggered orders and User-triggered orders).
* **Task Queue:** Celery or Redis Queue.
* **AI Engine:** Separate Microservice serving inference via REST/gRPC.

### Data Models (Simplified)
* `User`: Account info, Null Balance.
* `Order`: Buy/Sell records (Type: AUTO or MANUAL, Ticker, Price, Amount).
* `Strategy`: JSON configuration (for Auto trading).
* `Ledger`: Null transaction history.

### APIs and Integrations
* **Market Data Provider:** Real-time/Historical data API.
* **Internal AI API:** Probability scores.

# Development Roadmap
### Phase 1: Foundation & Backtesting (The Laboratory)
* **Scope:**
    * User Auth & DB Setup.
    * Market Data Ingestion pipeline.
    * **Strategy Builder (GUI Form).**
    * **Backtesting Engine.**
    * *Result:* Users can create strategies and see past performance.

### Phase 2: Forward Testing & Manual Trading (The Reality)
* **Scope:**
    * **Real-time Data Fetcher:** WebSocket integration.
    * **Null Ledger System:** Virtual accounting logic.
    * **Manual Order System:** API endpoints for direct user buy/sell.
    * **Scheduler:** For automated strategy execution.
    * **Dashboard:** Unified view of Auto & Manual portfolios.
    * *Result:* Live simulation with both auto and manual capabilities.

### Phase 3: Community & Optimization (Future)
* **Scope:**
    * Leaderboard (Auto vs. Manual ranking).
    * Strategy Sharing.
    * Advanced Order Types (Limit, Market, Stop-loss).

# Logical Dependency Chain
1.  **Data Layer (Foundation):** Establish Market Data DB & API Connection.
2.  **Backend Core:** User Auth -> Null Ledger System (Wallet logic).
3.  **Backtesting Logic:** Simulation on past data.
4.  **Frontend MVP:** Strategy Builder & Backtest Result View.
5.  **Real-time Infra:** WebSocket for live prices.
6.  **Trading Engine (Integrated):**
    * Build **Manual Order API** first (Simpler: User requests -> Check Price -> Execute).
    * Build **Scheduler** next (Complex: Loop all strategies -> Check Logic -> Execute).

# Risks and Mitigations
* **Risk: Data Latency.** (실시간 데이터 지연)
    * *Mitigation:* Reliable API usage & Slippage implementation.
* **Risk: User Confusion.** (자동 매매 잔고와 수동 매매 잔고의 혼동)
    * *Mitigation:* UI에서 자동 매매용 '할당 자산(Allocated)'과 수동 매매용 '가용 자산(Available)'을 명확히 구분 표시.
* **Risk: AI Reliability.**
    * *Mitigation:* Display AI confidence intervals.

# Appendix
* **Initial Indicator Set:** SMA, RSI, Bollinger Bands, MACD.
* **Null Currency Rules:** 0.015% Virtual Commission applied to both Auto and Manual trades.
