# 널스탁 홍보 CF

흐름: **① 사전 점검 → ② 제품 화면 녹화(cf_run.sh) → ③ 대본 고치기(cf2_script.json) → ④ 모션그래픽+조립(cf2_run.sh)
→ ⑤ 검수·사용자 시청 → ⑥ 소개 글 미리보기 → ⑦ 게시.**
도구는 `.claude/skills/x-backtest-post/scripts/cf/`에 있다(스튜디오 녹화 도구 `../studio_*.mjs`·`../render_studio.py`를 함께 쓴다).

## 먼저 지킬 것

- **규제 안전 원칙(CLAUDE.md)** — 대본·화면 문구·게시 글 모두 "추천", "유망", "수익", "도움을 드린다(조언처럼 들리는 말)"를 쓰지 않는다.
  사용자가 **직접 설계·검증한다**는 사실과 기능 설명만 쓴다. 2026-10-12 사용자가 "도움을 줄 수 있는 서비스"로 시작하자고 했을 때
  "고민하던 아이디어를, 직접 설계하고 검증하는 곳"으로 풀었다 — 표현을 바꿨으면 바꾼 이유를 보고한다.
- **끝 카드에 면책 문구를 넣는다**(X 백테스트 글의 면책 생략 지시와 별개 — 광고물). 단 **아주 작게**(15px, 화면 맨 아래 — 10-12 사용자 지시 "폰트가 너무 커").
- **게시·삭제는 사용자 몫**이다. 미리보기 없이 올리지 않고, 기존 글은 요청 없이 지우지 않는다.
- **작업 폴더는 `~/nullstock-cf/<날짜>/`** — 세션 스크래치(`/private/tmp/...`)는 세션이 다시 시작되면 통째로 비워진다
  (10-12: 녹화 프레임·녹음·Playwright가 모두 사라져 재편집 불가). Playwright는 `~/nullstock-cf/pw`에 한 번 설치해 링크한다.
- **완성 파일은 덮어쓰지 않는다** — 열린 QuickTime 파일을 같은 이름으로 덮어써 "영상이 아무것도 안 보여" 사고(10-12). 이름에 시각·버전을 붙이고,
  보여 줄 때는 `osascript -e 'tell application "QuickTime Player" to quit'` 뒤 `open -a "QuickTime Player" <새 파일>`.

## ① 사전 점검

```bash
date                                                     # 장중(평일 09:00~15:30)이면 실제 시세, 아니면 --demo-quotes
curl -s localhost:3000 -o /dev/null -w "%{http_code}\n"  # 프론트·백엔드가 떠 있어야 한다
# OpenRouter: 무료 모델로 실제 1건 호출 → 429면 한도 소진(09:00 KST 초기화). 소진 상태로 찍으면 9B로 넘어가 해석이 수 분
B=~/nullstock-cf; mkdir -p $B/pw && cd $B/pw && npm init -y >/dev/null && npm i playwright && npx playwright install chromium   # 처음 한 번
```

## ② 제품 화면 녹화 — `cf_run.sh` (약 7분, 1편 영상까지 나온다)

```bash
W=~/nullstock-cf/$(date +%m%d); mkdir -p $W && ln -sfn ~/nullstock-cf/pw/node_modules $W/node_modules
export GUEST_PW="$(python3 -c "import json;print([x for x in json.load(open('guest-accounts.local.json')) if x['guestId']=='guest_5312'][0]['password'])")"   # 출력·기록 금지
bash .claude/skills/x-backtest-post/scripts/cf/cf_run.sh $W .claude/skills/x-backtest-post/scripts/cf/cf_spec.example.json [--demo-quotes]
```

- 한 브라우저에서: 문장 입력 → 해석 카드 → 칩 답변 → 백테스트 → 전략 최적화 → 워크포워드(약 3분 30초) → 몬테카를로(2,000회)
  → 계좌 만들기 → 모의투자 상세(시세 채워질 때까지 대기) → 종목 화면. 결과는 `$W/nullstock_cf.mp4`(1편 형식)와 녹화 원본.
- `cf_spec.example.json`의 문장은 첫 화면 예시 "PER·PBR·거래대금 조건"(10-11 사용자 선택). 바꾸면 예시 게이트를 거친 문장만 쓴다.
  준비된 칩 답이 없는 질문이 나오면 녹화가 멈춘다 — `answers`에 넣고 처음부터 다시.
- **해석 요약이 문장과 같은지 확인**한다(run.log에 출력) — 어긋나면 만들지 말고 보고.
- **장이 닫힌 날** `--demo-quotes`: 마지막 종가에 결정적 무작위 걸음을 얹고 영상에 "시연용 연출 화면" 표기가 붙는다(10-11 사용자: "실시간 시세처럼 보여주면 돼").
  녹화 폴더에 `demo_quotes.flag`가 남아 ④ 2편 조립도 가상계좌 장면에 같은 표기를 얹는다(10-13 계약 검토 지적으로 보강).
- 수동 주문 패널은 제품에서 꺼져 있다(`SHOW_TRADE_PANEL=false`) — 주문 장면을 연출하지 않는다(가상계좌=전략 신호 기반 모의 체결).
- 녹화마다 **운영 DB 데모 계정에 백테스트 기록·저장 전략·가상계좌가 남는다** — 끝나면 사용자에게 알리고 둘지 묻는다
  (10-12 'PER·PBR 가상계좌'는 사용자 지시로 유지). 해지는 `DELETE /api/virtual-account/<id>`(상세의 '계좌닫기'는 화면만 닫는다).

## ③ 대본 — `cf2_script.json` 하나만 고친다

화면 문구(`copy`), 장면 길이(`scenes`), 내레이션 줄(`lines`)이 한 파일에 있다. 모션 렌더와 조립이 같은 파일을 읽는다.

- 줄 배치: `"at": "m:open", "offset": 0.6`(장면 시작 기준) 또는 `"after": "v3", "gap": 0.35`(앞 줄이 끝난 뒤).
  장면 이름: `m:open m:heat m:title p:backtest m:wf p:wf m:mc p:mc m:live p:account m:end`(m=모션, p=제품 화면).
- 숫자는 `text`에 한글로("이천 번" — TTS가 읽게), `sub`에 아라비아 숫자로("2,000번" — 자막).
- **현재 대본의 흐름(10-12 사용자 지시)**: 시장의 복잡함 → "어떤 전략을 만들어야 할지 고민" → "널스탁에서 시작해 보세요"
  → 문장→조건→백테스트 → **"결과가 나왔다면, 이제 한 번 더 확실하게 검증합니다"**(백테스트 결과 화면 끝에서 시작)
  → 워크포워드·몬테카를로를 '다시 검증'으로 소개(부제 "한 번 더, 확실하게 검증" / "2,000개 시나리오로 다시 검증") → 가상계좌 → 끝.
  "시장은 매일 수천 개의 신호를 보냅니다"식 오프닝은 서비스와 연결이 부자연스럽다는 피드백으로 버렸다.
- 줄이 길어지면 그 장면 길이를 늘린다 — 조립이 `[경고] vX가 다음 줄과 N초 겹친다`를 출력하면 고친다. 전체는 60초 안팎.

## ④ 모션그래픽 + 조립 — `cf2_run.sh` (약 3분 + TTS)

```bash
bash .claude/skills/x-backtest-post/scripts/cf/cf2_run.sh $W ~/nullstock-cf/$(date +%m%d)/cf2 [대본.json] [출력 이름]
```

`cf2_assets.py`(실제 KOSPI 일봉·주봉, KOSPI200 종가·등락률, 투명 로고) → `render_motion.mjs`(motion.html 장면 프레임, 대본의 copy 주입)
→ `cf2_build.py`(제품 클립을 브라우저 창 액자에 넣고 모션과 엮음, 내레이션 합성, 음악 `cf_music.py`, 사이드체인 덕킹, -14 LUFS).

- **내레이션 = Gemini TTS**(`cf_tts_gemini.py`, 음성 Charon, `.env` GOOGLE_API_KEY, 대본 문구만 Google로 전송).
  - **무료 한도는 모델별 하루 10건** — 10줄이면 한 모델의 하루치다. 소진되면 `cf2_script.json`의 `tts_model`을 다른 TTS 모델로 바꾸고
    **10줄 전부** 다시 합성한다(한 편 안에서 모델이 섞이면 목소리가 달라진다). 모델 목록: `GET /v1beta/models`에서 `tts` 포함.
    10-12 사용: gemini-3.8-flash-tts → 2.5-flash-preview-tts → 3.1-flash-tts-preview(현재 대본). 남은 후보: 2.5-pro-preview-tts·3.8-flash-lite-tts.
  - 합성 결과는 `cf2_work/<줄>_<해시>.wav` — 문장·음성·모델이 같으면 다시 부르지 않는다(대본을 고친 줄만 다시 합성).
  - **말투 지시문을 넣지 않는다** — "차분한 광고 톤으로 읽어 주세요" 같은 지시문을 한국어·영어 모두 소리 내어 읽었다(5초 문장이 11~13초).
  - 분당 한도(429)가 있어 줄 사이 22초 간격(`CF_TTS_GAP`) + 재시도. edge-tts(1편 원래 음성)는 10-12부터 403.
  - **합성 뒤 받아쓰기로 대조**: `python3 cf_vo_check.py cf2_work/*.wav` — 직접 들을 수 없으니 이것이 내레이션 검수다.
- 모션 장면의 흐림은 `layer()` 캐시로 한 번만 그린다 — 캔버스 `filter: blur`를 매 프레임 쓰면 헤드리스에서 프레임당 7초(10-12).
- **전광판·히트맵 숫자는 실제 마지막 종가·등락률 그대로** — 실제 종목명에 지어낸 가격 흔들림을 붙이지 않는다.

## ⑤ 검수 → 사용자 시청

- `*_sheet.png`(1초 간격 접촉 시트)와 원본 프레임 몇 장을 연다: 문구가 타일·차트와 겹치는지(히트맵 날짜 라벨 10-12 수리),
  시세가 채워지기 전 빈 칸 화면, 툴팁, 끝 카드 면책 크기.
- 음량은 `ffmpeg -af ebur128`로 -14 LUFS 안팎인지. **소리는 직접 못 듣는다** — 음악·톤은 사용자에게 들어 봐 달라고 한다.
- 바탕화면에 **새 이름으로** 복사하고 QuickTime을 닫았다 연다. 고친 영상마다 `_v2`, `_v3`…

## ⑥⑦ 소개 글과 게시

**글은 서비스 소개만**(10-12 사용자 지시): "널스탁을 소개합니다."로 시작해 서비스가 무엇을 하는지만 쓴다.
"2편입니다" 같은 회차 표현, 영상 속 전략 문장, 결과 수치, "이 전략 그대로 열기" 링크를 넣지 않는다. 끝에 홈페이지 링크(UTM)만.

```
널스탁을 소개합니다.

복잡한 주식 시장에서 어떤 전략을 만들어야 할지 고민될 때, 떠오른 아이디어를 문장으로 적어 보세요. 널스탁이 그 문장을 매수·매도 조건으로 해석하고, 과거 데이터로 바로 백테스트합니다.

백테스트 결과가 나오면 한 번 더 검증합니다.
· 워크포워드 분석: 학습 구간에서 맞춘 설정을 전략이 한 번도 보지 못한 구간에 적용해, 과거에만 맞춘 결과인지 확인합니다.
· 몬테카를로 시뮬레이션: 수익률 흐름을 수천 번 다시 섞어, 낙폭이 어디까지 커질 수 있는지 범위를 봅니다.

검증한 전략은 가상계좌에 연결해 실시간 시세로 모의투자할 수 있습니다. 실제 주문은 나가지 않습니다.

설계부터 검증, 모의투자까지. 투자 연구 플랫폼 널스탁
https://www.nullstock.im/?utm_source=x&utm_medium=social&utm_campaign=<cf-이름-YYYYMMDD>
```

```bash
uv run python scripts/post_to_x.py --file post.txt --long --video <영상>            # 미리보기
uv run python scripts/post_to_x.py --file post.txt --long --video <영상> --post     # 게시 → POSTED_ID
```

- 게시 뒤 API로 영상·본문을 조회해 확인하고 링크를 보고한다(x-backtest-post ⑤⑥의 조회 명령).
- AI 리포트 요약 답글은 달지 않는다(홍보 글 — 10-12 사용자 선택).
- 같은 영상의 이전 글이 남아 있으면 삭제 여부를 묻는다(요청 없이 지우지 않는다).
